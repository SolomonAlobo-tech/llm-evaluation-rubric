# LLM Response Evaluation Rubric

A practical rubric for evaluating and comparing responses from large language models (LLMs). It covers single-response scoring, side-by-side (SxS) comparison, and hallucination checks.

> All examples in this repository are made up for demonstration. No real client, project, or platform data is included.

## What's inside
| File | Purpose |
|------|---------|
| `rubric.md` | The scoring criteria, scale, and decision rules |
| `sample-evaluations.md` | Worked examples with scores and written justifications |

## How to use it
1. Read the prompt and any source material first.
2. Score each response on the five criteria in `rubric.md`.
3. Write a short justification for every score.
4. For SxS comparisons, follow the tie-breaking rules.
5. Flag any hallucinations or safety issues separately.

## Why this approach
- **Consistent:** the same criteria apply to every response
- **Justified:** every score needs a written reason
- **Transparent:** severe issues (hallucination, safety) are flagged, not averaged away
